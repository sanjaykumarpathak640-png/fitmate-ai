# Demo video script (about 3 minutes)

Run the backend in real mode (`uvicorn main:app --port 8000`, ideally with `HF_TOKEN`) and open http://localhost:8000/. Have one tester ready.

| Time | Screen | Say / do |
|---|---|---|
| 0:00 | Home | "Online shoppers can't see how clothes look on them or which size fits. FitMate answers both, separately." |
| 0:15 | My Avatar | Pick a template; open Face (close-up) and change face shape, nose, lips; Hair: style, colour, beard; Skin tone; then Body: move height, chest and waist; press 360°. "A realistic 3D you, and it measures exactly your centimetres." |
| 0:40 | Wardrobe | Switch Boys/Girls, filter Kurtas, pick a shirt, change colour. "100 garments, every colour and size." |
| 1:00 | Wardrobe → sizes | Click XS: red tight markers appear; click the "Your size" button: they disappear. "Each size is drawn from its real chart." |
| 1:20 | Fit Report | Size, three scores, "Why this recommendation?", every size compared. Switch to a garment with a missing chart: confidence drops and says why. |
| 1:50 | Photo Try-On | Upload your photo (consent), overlay, then Generate AI try-on; show Compare. Delete photo. |
| 2:25 | Style Studio | Festive colour match; ₹1,000 outfit using owned jeans; Wear this outfit. |
| 2:40 | Testing | Run all checks (18/18). Show the recorded user tests and agreement rate. |
| 2:55 | Project page | "Limitations and next steps are here. Thank you, Team CodeCodders." |

If the GPU Space is busy, say so on camera. Never present the overlay or a mock result as AI.
